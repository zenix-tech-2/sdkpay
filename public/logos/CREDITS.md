# Bundled icon credits

Assets are bundled locally under `public/logos` so the UI does not depend on third-party CDNs at runtime.

Sources:
- Country flags: lipis/flag-icons (https://github.com/lipis/flag-icons), MIT.
- Regional / province flags: amckenna41/iso3166-flags (https://github.com/amckenna41/iso3166-flags).
- Card, wallet and APM logos: datatrans/payment-logos (https://github.com/datatrans/payment-logos).
- Mobile money marks and generic payment logos: aloahmilton/paybrand (https://github.com/aloahmilton/paybrand).
- Official-style Mobile Money marks: Yupixi/frontend (https://github.com/Yupixi/frontend) and kouakoumark9-blip/Mybigmarket (https://github.com/kouakoumark9-blip/Mybigmarket).
- Crypto icons: spothq/cryptocurrency-icons (https://github.com/spothq/cryptocurrency-icons).
- Generated fallback badges are original SDK Pay placeholders created from brand colors.

Provider names and marks remain the property of their respective owners. Review each upstream repository license and trademark terms before commercial deployment.

- Generated province badges: original SDK Pay region placeholders with ISO-style codes, used to fill gaps where upstream datasets have no subdivision flag.
